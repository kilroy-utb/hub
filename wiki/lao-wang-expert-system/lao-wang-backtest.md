## 方法（反未来函数的紀律）

| 項目 | 設定 |

| 視窗 | 2015-01-01 ～ 2026-11-22（2,900 個交易日） |
| Universe | 24 檔（依她的內容提及頻率選出，故有選樣偏差）：2330/2317/2454/2324/2323/2357/3231/2353/2412/2303/2327/2344/2337/2409/3481/1303/4958/3037/2313/2492/2328/3706/2408/6770 |

| 時間紀律 | 訊號只用 t 日收盤以前的資料；成交在 t+1 開盤 → 無 look-ahead |
| 成本 | 買 0.25%、賣 0.40%（含手續費與交易稅）；另設「漲停鎖死跳過進場」過濾 |
| 部位 | 單股 long/flat，組合等權重；未持倉為現金（不計利息） |
| 基準規則 base | 突破 126 日波段高 ＋ vol ≥ 2×MA20(vol) ＋ 收盤站上 MA5/10/20 ＋ 出場＝收盤跌破 MA10 |
| 信賴區間 | cluster bootstrap，分群為 (股票, 月份) |

## 參數掃描（36 組）

維度：波段高 63/126/252 日 × 爆量 1.5/2/3 倍 × 出場 MA5/10/20/60。

- **36/36 平均報酬為正、35/36 超額為正**（唯一負的是 252 日高＋3 倍量＋MA5 出場，−0.36%/筆）→ 結果不是單點參數的僥倖。
- 出場線越鬆越好（就平均報酬而言）：MA5 +0.36% → MA10 +1.69% → MA20 +3.63% → MA60 +10.4%（超額/筆），但回撤與曝險同步上升。
- 突破視窗越長越好：63 日 +3.22% → 126 日 +4.07% → 252 日 +4.77%。
- 爆量倍數越高越好但交易數急減：1.5× 5,125 筆 → 3× 2,096 筆。

## 判讀

1. **她的進場濾網是真價值**。完全拿掉進場條件、只用她的出場規則：9,861 筆、平均每筆 −0.04%、PF 0.98、maxDD −74.6%。加上進場條件：每筆 +2.79%、PF 1.92、maxDD −7.9%。價值來自「挑什麼時點進場」，不是「挑哪檔股票」。
2. **突破條件貢獻最大**：拿掉它，每筆超額從 +1.78% 掉到 +0.46%，回撤翻倍。
3. **爆量條件在此 universe 沒有加分**（差 0.15pp，CAGR 反而更高）。推測它在流動性差／處置股脈絡才有意義，而那層目前無法建模。
4. **均線對齊與月/季線閘門是冗餘的**：突破 N 個月高點在數學上必然已在所有較短均線之上。她語言中的「三條短期均線站上」是同一狀態的另一種說法，不是獨立條件。
5. **MA10「一條線」出場是用報酬換回撤**：同進場下固定 20 日每筆 +4.03% vs MA10 的 +2.79%，但回撤 −7.9% vs −11.6%。這是風險偏好選擇，不是錯誤。
6. **win-rate 會誤殺這套系統**：命中率 41.9% 低於無條件基準 53.7%，但 PF 1.92、每筆超額 +1.78%、CI 不含 0。她的結構是低勝率、右偏、靠尾部大行情（「海闊天空」）。若以勝率當 KPI，這套規則在第一輪就被淘汰。

## 限制（解讀前必讀）

- Universe 只有 24 檔電子/傳產，且是**依她的 coverage 選出**（選樣偏差）；6770 只有 2023 年後資料。
- 未做同族群中性化：「超額」是相對 0050，不是相對同族群 → 有一部分數字其實是電子股 beta。
- Cluster bootstrap 只按 (股票, 月份) 分群；24 檔高度同質、同一 regime → **CI 偏狹，顯著性被高估**。
- 無做空、無外資/投信籌碼欄位、無處置股公告 → 她的 L3 可執行性規則目前無法完整建模。
- 成本與滑價為假設值；突破日常常跳空開高，t+1 開盤成交已含部分延遲，實際滑價可能更高。
- 「支撐導向停損」與「形態」未實作。
- 規則來自她的**語言**，不是她的持倉紀錄；也沒有對照她發言的實際時點。

## 下一步（依預期報酬排序）

1. 同族群／多因子對照組重算 edge，剔除電子股 beta；universe 扩到全市場流動股。
2. 接入外資・投信連買賣超與處置股公告 → 驗 L3 閘門（最可能真有增量的一層）。
3. 以關鍵幀／人工標注實作支撐導向停損。
4. 把同一份 spec→引擎→回測 流程套在第二家（籌碼/制度派）上。
